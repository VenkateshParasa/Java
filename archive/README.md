# Archive Directory

This directory contains historical files, backups, and deprecated content that is no longer actively used but preserved for reference.

## Directory Structure

```
archive/
├── backups/           # Backup files and ready-to-add content
├── deprecated/        # Old versions of files no longer in use
└── selenium-archived/ # Archived Selenium files from development
```

## Contents

### 📦 Backups
Contains backup files created during development:
- Exercise file backups (with timestamps)
- Ready-to-add content files (Day 21, 23, 25, 27-30, etc.)
- Intermediate development versions

### 🗄️ Deprecated
Files that have been replaced by newer versions:
- Old folder structure guides
- Previous master index versions
- Obsolete planning documents

### 🌐 Selenium Archived
Archived Selenium content files from Week 4-5 development that were consolidated into the main weekly files.

## Why These Files Are Archived

1. **Backups:** Created during development as safety checkpoints
2. **Deprecated:** Replaced by improved versions in the main project
3. **Selenium Archived:** Intermediate files that were merged into final versions

## Should You Use These Files?

**For Learning:** ❌ No - Use the current content in `docs/`

**For Reference:** ✅ Yes - If you need to see the development history or recover specific content

**For Contributing:** ⚠️ Check with project maintainers first

## Restoration

If you need to restore content from archived files:
1. Review the file to confirm it has the content you need
2. Check if equivalent content exists in the current structure
3. If needed, extract specific sections rather than restoring entire files
4. Update any references to match current file locations
