## Learning Paths

### Complete Beginner (75 days)
1. Start with [Getting Started](getting-started/README.md)
2. Follow the [Java Core Course](courses/java-core/course-overview.md) (30 days)
3. Practice with [Java Exercises](exercises/java-core/)
4. Take [Java Assessments](assessments/java-core-assessments.md)
5. Begin [Selenium Course](courses/selenium-automation/course-overview.md) (45 days)
6. Practice with [Selenium Exercises](exercises/selenium/)
7. Review [Deep Dives](deep-dives/) for advanced topics

### Experienced Programmer (45 days)
1. Quick Java review: Days 1-14
2. Focus on OOP and Collections: Days 15-21
3. Jump to Selenium Course (45 days)
4. Use Deep Dives for advanced concepts

### Java Developer Learning Selenium (30 days)
1. Review Java 8+ features if needed
2. Start Selenium Course directly
3. Focus on framework development (Days 38-45)
4. Study all Deep Dives for best practices
