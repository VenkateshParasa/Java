# Java Core Course

**Duration:** 30 Days (4 Weeks)  
**Level:** Beginner to Intermediate  
**Total Exercises:** 253+ hands-on coding exercises

---

## 📚 Course Overview

This comprehensive Java Core course covers fundamental to intermediate Java programming concepts through a structured 30-day curriculum. Each day includes detailed lessons, practical exercises, and real-world examples.

### Course Structure

The course is organized into 4 weeks, with each week focusing on specific Java concepts:

- **Week 1:** Java Fundamentals & Control Flow
- **Week 2:** Object-Oriented Programming (OOP)
- **Week 3:** Advanced Java Concepts
- **Week 4:** File I/O, Multithreading & Modern Java

## 🎯 Learning Objectives

By completing this course, you will:

- ✅ Master Java syntax and fundamental programming concepts
- ✅ Understand and apply Object-Oriented Programming principles
- ✅ Work with Java Collections Framework effectively
- ✅ Handle exceptions and errors properly
- ✅ Perform file I/O operations
- ✅ Implement multithreading and concurrency
- ✅ Use modern Java features (Lambda, Streams, Date/Time API)
- ✅ Write clean, maintainable, and efficient Java code
