# Java Core Fundamentals - 30 Day Learning Plan

## Course Overview
This course is designed to take you from beginner to intermediate Java developer in 30 days, with a focus on building strong fundamentals needed for Selenium automation.

---

## Week 1: Java Basics & Environment Setup

### Day 1: Introduction & Setup
- What is Java? JDK vs JRE vs JVM
- Installing JDK (version 11 or higher recommended)
- Setting up IDE (IntelliJ IDEA or Eclipse)
- Writing your first Java program (Hello World)
- Understanding main method
- Compiling and running Java programs
**Practice**: Create 3 different Hello World variations

### Day 2: Variables & Data Types
- Primitive data types (int, double, boolean, char, etc.)
- Reference types vs primitive types
- Variable declaration and initialization
- Type casting (implicit and explicit)
- Constants using final keyword
**Practice**: Create a program with different data types, perform type conversions

### Day 3: Operators & Expressions
- Arithmetic operators (+, -, *, /, %)
- Relational operators (==, !=, >, <, >=, <=)
- Logical operators (&&, ||, !)
- Assignment operators (=, +=, -=, etc.)
- Increment/Decrement operators (++, --)
- Operator precedence
**Practice**: Build a simple calculator program

### Day 4: Control Flow - Conditional Statements
- if statement
- if-else statement
- if-else-if ladder
- Nested if statements
- switch-case statement
- Ternary operator
**Practice**: Create programs for grade calculator, day of week finder

### Day 5: Control Flow - Loops
- while loop
- do-while loop
- for loop
- Enhanced for loop (for-each)
- Nested loops
- break and continue statements
**Practice**: Print patterns, factorial, Fibonacci series

### Day 6: Arrays - Part 1
- Declaring and initializing arrays
- Accessing array elements
- Array length property
- Single-dimensional arrays
- Iterating through arrays
- Common array operations
**Practice**: Find max/min in array, reverse array, sum of elements

### Day 7: Arrays - Part 2 & Review
- Multi-dimensional arrays
- Jagged arrays
- Arrays class utility methods
- Copying arrays
**Week 1 Review Project**: Build a student grade management system using arrays
**Assessment**: Review all Week 1 concepts

---

## Week 2: Object-Oriented Programming Fundamentals

### Day 8: Introduction to OOP & Classes
- What is Object-Oriented Programming?
- Classes and Objects
- Creating a class
- Instance variables and methods
- Creating objects using new keyword
- Accessing members using dot operator
**Practice**: Create classes for Car, Student, BankAccount

### Day 9: Constructors & this Keyword
- What are constructors?
- Default constructor
- Parameterized constructor
- Constructor overloading
- this keyword usage
- Constructor chaining
**Practice**: Create classes with multiple constructors

### Day 10: Methods & Method Overloading
- Defining methods
- Method parameters and return types
- Method overloading
- Variable arguments (varargs)
- Method vs Function
- Pass by value in Java
**Practice**: Create utility classes with overloaded methods

### Day 11: Encapsulation & Access Modifiers
- Encapsulation concept
- Access modifiers (public, private, protected, default)
- Getters and Setters
- Benefits of encapsulation
- Data hiding
**Practice**: Create properly encapsulated classes

### Day 12: Inheritance
- Inheritance concept and benefits
- extends keyword
- super keyword
- Method overriding
- Types of inheritance (single, multilevel, hierarchical)
- Why Java doesn't support multiple inheritance
**Practice**: Create inheritance hierarchy for Employee types

### Day 13: Polymorphism
- Compile-time polymorphism (method overloading)
- Runtime polymorphism (method overriding)
- Dynamic method dispatch
- Upcasting and downcasting
- instanceof operator
**Practice**: Create examples demonstrating polymorphism

### Day 14: Abstraction - Abstract Classes & Interfaces
- Abstract classes and methods
- abstract keyword
- Interfaces and implements keyword
- Multiple interface implementation
- Default and static methods in interfaces (Java 8+)
- When to use abstract class vs interface
**Week 2 Review Project**: Create a shape hierarchy with abstract classes/interfaces
**Assessment**: OOP concepts review

---

## Week 3: Advanced Java Concepts

### Day 15: Strings
- String class and immutability
- String creation (literal vs new)
- String pool concept
- String methods (length, charAt, substring, indexOf, etc.)
- String comparison (equals vs ==)
- StringBuilder and StringBuffer
**Practice**: String manipulation programs (palindrome, reverse, anagram)

### Day 16: Packages & Static Keyword
- Creating and using packages
- import statement
- Access control with packages
- static variables and methods
- static blocks
- static import
**Practice**: Organize classes into packages

### Day 17: Exception Handling - Part 1
- What are exceptions?
- try-catch block
- Multiple catch blocks
- finally block
- try-with-resources (Java 7+)
- throw keyword
**Practice**: Handle different exceptions in programs

### Day 18: Exception Handling - Part 2
- throws keyword
- Checked vs unchecked exceptions
- Creating custom exceptions
- Exception hierarchy
- Best practices for exception handling
**Practice**: Create custom exceptions for validation

### Day 19: Collections Framework - List & Set
- Collections Framework overview
- ArrayList class
- LinkedList class
- Vector and Stack
- HashSet, LinkedHashSet, TreeSet
- List vs Set
**Practice**: Work with different List and Set implementations

### Day 20: Collections Framework - Map & Utilities
- HashMap, LinkedHashMap, TreeMap
- Hashtable
- Collections utility class methods
- Arrays utility class methods
- Comparable vs Comparator
**Practice**: Create programs using Maps and sorting

### Day 21: Generics
- Why generics?
- Generic classes
- Generic methods
- Bounded type parameters
- Wildcards (?, extends, super)
- Type erasure concept
**Week 3 Review Project**: Create a generic data structure with exception handling
**Assessment**: Review Week 3 concepts

---

## Week 4: Essential Java Features

### Day 22: File Handling - Part 1
- File class
- Reading from files (FileReader, BufferedReader)
- Writing to files (FileWriter, BufferedWriter)
- File operations (create, delete, rename, exists)
**Practice**: Read and write text files

### Day 23: File Handling - Part 2
- FileInputStream and FileOutputStream
- Serialization and deserialization
- Try-with-resources for file handling
- Path and Files classes (NIO.2)
**Practice**: Serialize objects, work with binary files

### Day 24: Java 8 Features - Lambda & Streams
- Lambda expressions
- Functional interfaces
- Method references
- Stream API basics
- Filter, map, reduce operations
**Practice**: Use lambdas and streams for data processing

### Day 25: Date & Time API
- Old Date and Calendar classes
- Java 8 Date-Time API
- LocalDate, LocalTime, LocalDateTime
- ZonedDateTime
- Period and Duration
- Formatting and parsing dates
**Practice**: Work with dates in different formats

### Day 26: Wrapper Classes & Autoboxing
- Wrapper classes (Integer, Double, Boolean, etc.)
- Autoboxing and unboxing
- Utility methods of wrapper classes
- valueOf vs parseInt
**Practice**: Data conversion programs

### Day 27: Multithreading Basics
- Thread concept
- Creating threads (Thread class, Runnable interface)
- Thread lifecycle
- Thread methods (start, run, sleep, join)
- Thread synchronization basics
**Practice**: Create simple multithreaded programs

### Day 28: Inner Classes & Enums
- Inner classes (member, local, anonymous)
- Static nested classes
- Enumerations (enum)
- Enum constructors and methods
**Practice**: Use enums for constants, create inner classes

---

## Week 5: Practice & Projects

### Day 29: Comprehensive Review
- Review all major concepts
- Practice coding problems
- Debug and fix common errors
- Code refactoring practice

### Day 30: Final Project
**Project**: Build a Library Management System
- Features: Add books, issue books, return books, search books
- Requirements:
  - Use OOP principles (inheritance, polymorphism, encapsulation)
  - Exception handling for invalid operations
  - File I/O for data persistence
  - Collections for managing data
  - Proper package structure
