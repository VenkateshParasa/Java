# Week 1: Java Basics & Environment Setup

**Duration**: 7 Days | **Level**: Beginner | **Prerequisites**: None

---

## 📋 Overview

Week 1 introduces you to Java programming fundamentals. You'll set up your development environment, learn basic syntax, work with variables and operators, understand control flow, and master arrays. By the end of this week, you'll have a solid foundation to build upon.

---

## 🎯 Learning Objectives

By the end of Week 1, you will be able to:
- Set up Java development environment (JDK, IDE)
- Write, compile, and run Java programs
- Work with variables, data types, and operators
- Use conditional statements and loops
- Create and manipulate arrays (1D and 2D)
- Build a complete console application

## 💡 Tips for Success

### Study Tips:
1. **Practice Daily**: Code every day, even if just for 30 minutes
2. **Type Code**: Don't copy-paste; type everything yourself
3. **Experiment**: Modify examples to see what happens
4. **Debug**: Learn to read error messages
5. **Review**: Go back to previous days if needed

### Common Pitfalls to Avoid:
- Forgetting semicolons
- Off-by-one errors in arrays
- Using `==` instead of `.equals()` for Strings
- Integer division truncation
- Uninitialized variables
- Infinite loops

### Best Practices:
- Use meaningful variable names
- Follow naming conventions
- Comment your code
- Keep methods small and focused
- Handle edge cases
- Test your code thoroughly
