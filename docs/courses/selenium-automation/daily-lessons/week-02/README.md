# Week 2: Advanced WebDriver Techniques

## Overview

Welcome to Week 2\! Building on the fundamentals from Week 1, this week takes your Selenium skills to the next level. You'll learn advanced WebDriver techniques that are essential for handling complex web applications. From mastering mouse and keyboard interactions to working with dynamic tables, file operations, and challenging web elements, Week 2 prepares you for real-world automation scenarios.

## Learning Objectives

By the end of Week 2, you will be able to:

1. Perform advanced mouse operations using the Actions class (hover, drag, context menus)
2. Execute keyboard operations and shortcuts programmatically
3. Implement drag and drop functionality for various UI elements
4. Handle sliders, resizable elements, and sortable lists
5. Extract and interact with data in web tables (static and dynamic)
6. Automate file upload and download operations
7. Use JavaScript Executor for advanced element manipulation
8. Handle pop-ups, modal dialogs, and browser notifications
9. Work with Shadow DOM and iFrames effectively
10. Integrate multiple techniques to create comprehensive test scenarios
11. Build a mini e-commerce automation project

## Common Challenges & Solutions

### Challenge 1: Actions Not Working
**Solution**: Ensure you call perform() or build().perform(). Review Day 8 build vs perform section.

### Challenge 2: Drag and Drop Fails
**Solution**: Try multiple approaches (dragAndDrop, clickAndHold + move + release, JavaScript). See Day 9 workarounds.

### Challenge 3: Table Data Not Found
**Solution**: Check for pagination, dynamic loading, or iframes. Review Day 10 dynamic tables section.

### Challenge 4: File Upload Not Working
**Solution**: Verify element type="file", ensure path is absolute, consider Robot class. See Day 11.

### Challenge 5: JavaScript Executor Returns Null
**Solution**: Check return statement in JS code, verify element is in DOM. Review Day 12.

### Challenge 6: Shadow DOM Elements Not Found
**Solution**: Use JavaScript Executor to access shadow root. See Day 12 and Day 13.
