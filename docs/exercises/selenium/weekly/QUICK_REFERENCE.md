## Key Topics by Week

### Week 4 - Element Location & Interaction
- **XPath:** Basics, axes, functions, dynamic elements, tables, best practices
- **CSS Selectors:** ID/class/attributes, combinators, pseudo-classes, performance
- **Form Elements:** Dropdowns (Select class), checkboxes, radio buttons
- **Alerts:** JavaScript alerts, confirms, prompts, popups

### Week 5 - Framework & Advanced Techniques
- **TestNG:** XML configuration, groups, dependencies, parameters
- **Page Object Model:** Factory pattern, lazy initialization
- **JavaScript Executor:** Browser interactions, scrolling, hidden elements
- **Waits:** Implicit (global), Explicit (conditional), Fluent (custom polling)
- **Screenshots:** Full page, element-specific, failure capture, management
