# Week 1: Selenium Fundamentals & Core Concepts

## Overview

Welcome to Week 1 of your Selenium automation journey\! This week lays the foundation for everything you'll learn in this course. You'll discover what Selenium is, how to set it up, and master the core concepts needed to write effective automation scripts. By the end of this week, you'll be able to create basic automated tests using Selenium WebDriver.

## Learning Objectives

By the end of Week 1, you will be able to:

1. Understand what Selenium is and its various components
2. Set up Selenium WebDriver in your development environment
3. Master all 8 locator strategies to find web elements
4. Execute browser commands and manage browser windows
5. Interact with various types of web elements
6. Implement proper synchronization using waits
7. Handle special elements like dropdowns, alerts, and frames
8. Set up a basic test automation framework using TestNG
9. Write and execute automated test scripts
10. Apply best practices for maintainable automation code

## Common Challenges & Solutions

### Challenge 1: Element Not Found
**Solution**: Review locator strategies (Day 2) and ensure elements are present before interacting

### Challenge 2: Tests Are Flaky
**Solution**: Implement proper waits (Day 5) instead of using Thread.sleep()

### Challenge 3: StaleElementReferenceException
**Solution**: Re-locate elements after page updates (Day 4)

### Challenge 4: Can't Switch to Alert/Frame
**Solution**: Review switching techniques (Day 6) and ensure proper context

### Challenge 5: WebDriver Executable Path Issues
**Solution**: Ensure browser drivers are in system PATH or use WebDriverManager
