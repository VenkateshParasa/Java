## 🎨 DESIGN STANDARDS

### Visual Consistency

**Color Scheme:**
- Primary: #2563eb (blue)
- Success: #10b981 (green)
- Warning: #f59e0b (orange)
- Error: #ef4444 (red)
- Neutral: #6b7280 (gray)

**Typography:**
- Code: `Consolas`, `Monaco`, monospace
- Headings: Bold, clear hierarchy
- Body: Readable, consistent sizing

**Layout:**
- Consistent spacing
- Clear labels
- Logical flow direction (top-to-bottom, left-to-right)
